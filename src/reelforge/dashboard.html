新手指南

三步上手

  1. 在创作里选图片，写一句提示词——不会写就展开套用风格模板， 填主体 / 动作 / 场景，自动拼成专业提示词。一张草稿几分钱，多生几张挑。
  2. 图满意了就让它动起来：把鼠标移到图上点用这张生视频， 或切到视频后在参数栏点参考图挑一张。 先用 480P + 4–5 秒试一版，大约两毛多，满意再换 768P 出正式版。
  3. 想要带配乐、卡点剪辑的成片：让 Claude Code 跑 reelforge run， 回任务看进度、选关键帧、看成片。

花钱规则

生成前页面一定先显示预计花费；所有消费都走同一个总额度上限， 超了会被直接拒绝，不会偷偷扣钱。
顶部的 fal 余额是账户实时余额，约 30 秒刷新一次； 旁边的进度条是「已花 / 上限」。

提示词技巧

  • 写具体：主体是什么 + 光从哪来，硬光还是逆光轮廓光 + 什么颜色撞什么颜色 + 什么镜头，例如 35mm 或微距。
  • 别写「好看的氛围感」这类虚词，模板已经把这些打包好了。
  • 做系列时主体描述一字不改，主角才不会走样。

名词解释

文生视频　一句话直接出视频，快，但画面不可控。
从图片生成　先挑一张满意的图再让它动起来，可控，正经做内容走这条； 入口是视频参数栏的参考图，或结果图上的用这张生视频。
关键帧　每个镜头的第一帧，你选中的那张决定这个镜头长什么样。
drop　音乐情绪最高点，批量任务会把最炸的镜头切在这里。
