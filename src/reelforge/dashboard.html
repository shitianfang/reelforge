怎么少花钱

  • 批量任务在 jobs/*.yaml 里写 budget_usd， 单个任务超预算会停下来问你。

新手指南

三步上手
  1. 在创作里选图片，写一句提示词——不会写就展开套用风格模板，填主体、动作、场景，自动拼成提示词（以英文为主，模型更听英文）。一张草稿几分钱，多生几张挑。
  2. 图满意了就让它动起来：在图片卡片上点用这张生视频，或切到视频后在参数栏点参考图挑一张。先用 480P + 4–5 秒试一版，大约两毛多，满意再换 768P 出正式版。
  3. 想要带配乐、卡点剪辑的成片：让 Claude Code 跑 reelforge run，回任务看进度、选关键帧、看成片。
花钱规则
生成前页面一定先显示预计花费；所有消费都走同一个总额度上限，超了会被直接拒绝，不会偷偷扣钱。
顶部的余额是 fal 账户里真实的钱，约 30 秒刷新一次；旁边那条细进度条是本机自己设的上限用掉了多少，两者不是一回事。
上限用尽时生成按钮会变灰，按钮旁边会写清楚原因和去哪儿改。
提示词技巧
  • 写具体：主体是什么 + 光从哪来，硬光还是逆光轮廓光 + 什么颜色撞什么颜色 + 什么镜头，例如 35mm 或微距。
  • 别写「好看的氛围感」这类虚词，模板已经把这些打包好了。
  • 做系列时主体描述一字不改，主角才不会走样。
名词解释
文生视频
一句话直接出视频，快，但画面不可控。
从图片生成
先挑一张满意的图再让它动起来，可控，正经做内容走这条；入口是视频参数栏的参考图，或结果图上的用这张生视频。
关键帧
每个镜头的第一帧，你选中的那张决定这个镜头长什么样。
drop
